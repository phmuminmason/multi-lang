   		Proof?
   		Setup
	   		The bit we actually care about is X. X is always a multiple of 2.
	   		N is the number we're trying to check.
	   		The result of N % X = R.
	   		Y is the place value adjacent to X (X*2).

   		Conjecture: (N-R) % Y by it will let us see if the X bit is set. 

   		1. R can only be a value between 0 and X-1
   		2. Subtracting R from X can never clear the X bit because it only affects less significant bits; X-R will always leave the X bit set if it were ever set.
   		3. N-R has all of its bits before X cleared
   		4. (N-R) % Y returns all the bits right of Y; because only the X bit has not been changed, if the result of the Y calculation is not zero, X was set

   		Does this apply to X values that are not multiples of 2?

   		N = 0b1101001 -> 105
   		X = 0b0000101 -> 5

   		105 % 5 = 0

   		No, X must be broken up into powers of 2

   		105 % 4 = 1
   		104 % 8 = 0
   		4 bit is not set

   		Remember that we're AND-ing these two numbers!

   		105 % 1 = 0
   		105 % 2 = 1

   		1 bit is set!

   		105 & 5 = 1 !!!

   		OK so I'm pretty sure this is correct
   		
   		Simulating N & X:
	   		R = N % X
	   		Y = X * 2
	   		if (N-R)%Y == 0 then X bit was not set
	   		if (N-R)%Y == X then X bit was set

	   		If X is not a power of 2, it must be broken up into powers of two, each getting their own check
